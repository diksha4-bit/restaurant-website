# Restaurant Website

A responsive restaurant website built with HTML, CSS, and JavaScript as a personal practice and freelance demo project.

## Features

- Responsive design
- Restaurant menu with category filtering
- Image gallery
- Customer reviews
- Reservation section
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was created to practice frontend web development and demonstrate a website concept for a small restaurant business.
